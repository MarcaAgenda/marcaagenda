MARCAAGENDA — ATUALIZAÇÃO PARA APLICATIVO INSTALÁVEL

1. Extraia este ZIP no computador.
2. No repositório carlosjesus12343-cpu/marcaagenda, envie os arquivos extraídos para a raiz (Add file > Upload files). Mantenha a pasta icons com seus três PNGs. Não envie somente o ZIP.
3. Confirme as substituições e aguarde o GitHub Pages terminar a publicação.
4. Abra https://carlosjesus12343-cpu.github.io/marcaagenda/instalar.html
5. No iPhone: Safari > Compartilhar > Adicionar à Tela de Início.
   No Android: Chrome > Instalar MarcaAgenda (ou menu > Instalar app).

O pacote contém apenas arquivos novos/alterados. Base: commit 557aa76b7a675809c2f4d9d2224660fc88719771. Caso o repositório tenha mudado depois dessa versão, revise antes de substituir.
